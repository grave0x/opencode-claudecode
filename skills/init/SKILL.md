# Init Skill

## Protocol
1. Understand project type (lib, app, CLI, API)
2. Scaffold directory structure
3. Set up config files (tsconfig, eslint, prettier, gitignore, editorconfig)
4. Initialize package manager (npm/yarn/pnpm)
5. Set up CI config (GitHub Actions)
6. Create README with badges and quickstart
7. Initialize git repo + first commit

## Conventions
- Follow repo's existing patterns if modifying an existing project
- Use standard tooling for the ecosystem (no custom build scripts)
- Pin dependency versions
